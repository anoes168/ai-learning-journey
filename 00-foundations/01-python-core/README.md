# Python核心基础

## 我在哪里遇到了它

重构数据下载与传统机器学习基线时，需要理解函数、参数、返回值、模块导入和程序入口。

## 当前掌握

- 函数把一段操作封装成可以重复调用的代码。
- `return` 把函数内部产生的结果交给调用者。
- 直接运行文件时，`__name__` 的值是 `"__main__"`。
- 文件被其他文件导入时，`__name__` 通常是模块名。
- `if __name__ == "__main__":` 用来阻止导入模块时自动执行入口代码。
